PERSONA 2 - INTERFAZ DEL SISTEMA DE CONTROL DE ASISTENCIA

DISEÑO
- Tema oscuro sobrio: grafito, azul grisáceo, acero y blanco.
- Sin degradados, colores morados, brillos ni elementos decorativos innecesarios.
- Nombre genérico "Control de asistencia", ya que la empresa no tiene nombre definido.
- Diseño adaptable a computadora, tableta y celular.

ARCHIVOS
- index.html: inicio de sesión.
- registro.html: formulario de registro de usuario.
- menu.html: menú principal.
- css/estilos.css: estilos compartidos.
- js/app.js: interacciones y validaciones visuales.
- img/favicon.svg: favicon.

PRUEBA
1. Extrae el ZIP completo.
2. Abre index.html en un navegador.
3. Usa el enlace "Solicitar registro" para abrir el formulario.
4. Abre menu.html directamente para revisar el menú principal.
5. En el formulario de registro, escribe dos contraseñas distintas para comprobar la validación.

ALCANCE ACTUAL
Esta entrega es la interfaz del lado del cliente (HTML, CSS y JavaScript). No contiene base de datos, autenticación real ni almacenamiento de registros.
Los formularios no envían datos a un servidor todavía. Los módulos de entrada, salida y consulta muestran un aviso porque sus rutas y procesos dependen de la definición del backend y de la coordinación con el resto del equipo.
La validación JavaScript es únicamente de apoyo visual; cuando exista backend también se deberán validar los datos en el servidor.
